# Security

Tsuyaku runs a program on your PC that Firefox starts through native messaging, and that program
downloads models and helper programs. If you find a way for a web page, a stream, a chat message
or a download to make it do something it shouldn't, please report it privately rather than in a
public issue: use
[GitHub's private vulnerability reporting](https://github.com/Chunibyodev/tsuyaku/security/advisories/new)
or email contact@chunibyo.dev.

Only the latest release gets security fixes.
