Tsuyaku settings

Tsuyaku is off. Turn it on to see and change its settings.

Speech recognition

Engine

Shorter phrases and pauses give faster but choppier subtitles. The Whisper window (6 s) makes Whisper several times faster on short phrases; 30 is stock Whisper. A new model is downloaded from the Tsuyaku button.

Translation model

The translator writes the subtitles and the chat translations, and the message box's Japanese unless a cloud model is chosen below. Ollama or LM Studio work as an external server.

Message box

Type English in YouTube's chat box: Japanese versions, each translated back into English, appear about a second after you stop typing.

Get a free key

If the cloud model fails or reaches its free limit, the local model takes over. Keys are stored in Tsuyaku's config file on this PC.

Glossary

Names and terms for the translator, for every stream or one channel (e.g. ぺこら → Pekora). Channels appear here after you've watched them.
